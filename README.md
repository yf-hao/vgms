# VGMS填报助手

这是一个仅针对 `https://vgms.fanyu.com` 的 Chrome Manifest V3 扩展。目前提供“课题”Tab，可从 Markdown 模板读取各标题下的内容或手动输入，再尝试填写课题基本信息及动态表单；“选题”Tab 作为后续功能入口。扩展不会自动提交表单。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角的“开发者模式”。
3. 选择“加载已解压的扩展程序”，并选择本项目目录。

## 课题填写说明

### 单条填写

1. 登录 VGMS，打开扩展，在“课题”Tab 点击“导入 Markdown 模板”，再选择导入单个模板；也可以手动输入信息。
2. 检查内容并点击“保存并等待填表”。
3. 打开“新增”课题表单；扩展会尝试填写。检查选项和内容后，再手动操作网页按钮。

也可以先打开课题申报表单，再打开扩展导入信息。

### 批量填写

1. 在扩展的“课题”Tab 点击“导入 Markdown 模板”，再选择“导入文件夹（批量）”；检查第一份模板预览后点击“开始批量填报”。
2. 扩展按文件名自然排序，依次填写模板。每个文件对应一条课题记录。
3. 检查当前记录并点击网页上的“确定并继续”；扩展会等待下一张空白表单出现，再填写下一份模板。
4. 最后一份点击“确定”结束批次。也可以随时点击扩展中的“取消等待”停止并清除剩余模板。

### 字段映射

1. 课题可选范围（`org_ids`）
2. 所属专业（`org_id`）
3. 课题名称（`name`）
4. 课题来源（radio `source`）
5. 课题类型（radio `subjectType`）
6. 文科/理科（radio `tpltypes`）
7. 课题简介（textarea `text1`）

动态表单加载后，扩展会继续填写第 4 至第 7 项。树形选项按完整文本匹配；如果有多个同名选项，会显示组织路径供你选择。扩展点击匹配选项的选择图标；课题可选范围是多选项，还会点击组件内的“确定”。找不到选项或组件未接受选择时，扩展会提示检查，不会猜测或自动提交。

### Markdown 模板格式

每个模板使用以下标题，正文写在对应标题下：

```markdown
## 课题可选范围
计算机科学与技术专业

## 所属专业
计算机科学与技术专业

## 课题名称
基于深度学习的图像识别技术研究

## 课题来源
自选课题

## 课题类型
工程实践

## 文科/理科
理科

## 课题简介
课题背景和主要内容。
预期成果及表现形式。
```

正文会去除首尾空白并压缩多余空格。同一段中的折行合并为空格；连续空行作为一个段落分隔，段落之间保留一个换行。

### 数据与限制

- Markdown 文件由扩展弹窗在本地读取，不会上传。
- 等待中的填表数据保存在 Chrome 扩展本地；批次完成或点击“取消等待”后清除。
- 每次重新打开扩展弹窗时，“申报信息”输入区默认为空。
- 扩展只负责填写，不会自动点击“确定”“确定并继续”等提交按钮。
