# VGMS填报助手

这是一个仅针对 `https://vgms.fanyu.com` 的 Chrome Manifest V3 扩展。目前提供“登录”Tab，可保存学校、账号和密码，并在登录页自动填写、勾选协议；“课题”Tab 可从 Markdown 模板读取各标题下的内容或手动输入，再尝试填写课题基本信息及动态表单；“选题”Tab 可保存审核意见，并在审核弹窗中自动选择“通过”、填入意见，由你手动点击“确定并继续”。扩展不会自动提交任何表单。

## 项目结构

```text
vgms/
├── manifest.json
├── background/   # 扩展后台 service worker
├── popup/        # 侧边栏/浮动面板页面及其脚本和样式
├── content/      # 注入 VGMS 页面的脚本，按功能划分
├── shared/       # 弹窗与内容脚本共用的模块
└── 模板/         # 用户可导入的 Markdown 模板
```

`manifest.json` 必须留在扩展根目录；调整脚本或页面位置时，要同步更新清单中的路径和页面引用。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角的“开发者模式”。
3. 选择“加载已解压的扩展程序”，并选择本项目目录。
4. 后续更新时，修改此目录中的文件后，点击已安装扩展卡片上的“重新加载”，再刷新 VGMS 页面。请固定使用这个项目目录；如果要换目录，先移除 Chrome 中的现有扩展，再从新目录加载。

扩展 ID 固定在 `manifest.json` 中。启用固定 ID 前已经安装的旧副本 ID 不会自动迁移；首次加载后请在 `chrome://extensions` 手动移除那些旧副本。Chrome 按扩展 ID 管理安装，不会仅凭版本号自动合并或覆盖不同 ID 的扩展；同一 ID 的已解压扩展也不要从两个目录同时加载。

## 登录说明

1. 在扩展的“登录”Tab 中输入学校、账号和密码，然后点击“保存登录信息”。
2. 打开 VGMS 首页或 `https://vgms.fanyu.com/unified/auth/login`；扩展会在进入登录页后尝试选择匹配的学校、填写账号和密码，并勾选“我已阅读并同意”。
3. 检查登录信息后，手动点击网页上的“立即登录”。扩展不会自动登录。

登录信息保存在当前 Chrome 配置文件的扩展本地存储中，不会由本扩展上传；该存储不等同于加密密码库。请保护好当前浏览器配置文件，并避免在共享设备上保存密码。

## 课题填写说明

### 单条填写

1. 登录 VGMS，打开扩展，在“课题”Tab 点击“导入 Markdown 模板”，再选择导入单个模板；也可以手动输入信息。
2. 检查内容并点击“保存并等待填表”。
3. 打开“新增”课题表单；扩展会尝试填写。检查选项和内容后，再手动操作网页按钮。

也可以先打开课题申报表单，再打开扩展导入信息。



### 批量填写

1. 在扩展的“课题”Tab 点击“导入 Markdown 模板”，再选择“导入文件夹（批量）”；检查第一份模板预览后点击“开始批量填报”。
2. 扩展按文件名自然排序，依次填写模板。每个文件对应一条课题记录。
3. 检查当前记录并点击网页上的“确定并继续”；扩展会等待下一张空白表单出现，再填写下一份模板。
4. 最后一份点击“确定”结束批次。也可以随时点击扩展中的“取消等待”停止并清除剩余模板。

### 字段映射

1. 课题可选范围（`org_ids`）
2. 所属专业（`org_id`）
3. 课题名称（`name`）
4. 课题来源（radio `source`）
5. 课题类型（radio `subjectType`）
6. 文科/理科（radio `tpltypes`）
7. 课题简介（textarea `text1`）

动态表单加载后，扩展会继续填写第 4 至第 7 项。树形选项按完整文本匹配；如果有多个同名选项，会显示组织路径供你选择。扩展点击匹配选项的选择图标；课题可选范围是多选项，还会点击组件内的“确定”。找不到选项或组件未接受选择时，扩展会提示检查，不会猜测或自动提交。

### Markdown 模板格式

每个模板使用以下标题，正文写在对应标题下：

```markdown
## 课题可选范围
计算机科学与技术专业

## 所属专业
计算机科学与技术专业

## 课题名称
基于深度学习的图像识别技术研究

## 课题来源
自选课题

## 课题类型
工程实践

## 文科/理科
理科

## 课题简介
课题背景和主要内容。
预期成果及表现形式。
```

正文会去除首尾空白并压缩多余空格。同一段中的折行合并为空格；连续空行作为一个段落分隔，段落之间保留一个换行。

### 数据与限制

- Markdown 文件由扩展弹窗在本地读取，不会上传。
- 等待中的填表数据保存在 Chrome 扩展本地；批次完成或点击“取消等待”后清除。
- 每次重新打开扩展弹窗时，“申报信息”输入区默认为空。
- 扩展只负责填写，不会自动点击“确定”“确定并继续”等提交按钮。

## 选题审核自动填写

1. 在扩展的“选题”Tab 输入审核意见（只需输入一次），点击“保存并等待审核”。
2. 在 `https://vgms.fanyu.com/admin/index` 点击某条选题的“审核”打开弹窗；扩展会选择“通过”并填入审核意见。
3. 检查后手动点击“确定并继续”。下一位学生的审核表单加载后会自动重复填写，使用同一条审核意见；点击“停止填写”可结束。

扩展不会选择“不通过”，也不会自动点击任何提交按钮。审核意见保存在当前 Chrome 配置文件的扩展本地存储中。

## 任务书自动填写

1. 在“任务书”标签点击“导入 Markdown 模板”选择文件（也可直接在下方文本框输入或粘贴并修改；内容含 `# 研究（设计）目的与任务`、`# 基本要求`、`# 进度安排` 表格、`# 提交时间`），确认预览后点击“保存并等待填表”。
2. 在 VGMS 后台打开该学生的任务书编辑弹窗，插件会自动填写目的与任务、基本要求、提交时间，并按进度安排表格新增行、填写起止日期和主要任务。
3. 填写完成后请自行检查并点击“立即提交”，插件不会自动提交。填写后待填数据会清除；需要给下一位学生填写时重新导入模板。

日期会从“2026年10月27日”转换为“2026-10-27”。

## 侧边栏与浮动面板

- 默认使用侧边栏：点击工具栏图标在浏览器右侧打开，点击页面不会关闭（需要 Chrome 114 及以上）。
- 点击面板标题右侧的切换图标，改为页面内浮动面板：右下角“VGMS助手”按钮展开，可拖动标题栏移动（窗口大小固定）、点“×”收起，位置会记住。再点同一位置的图标可切回侧边栏。
- 模式选择会保存；浮动模式下点击工具栏图标也会展开浮动面板。
- 更新后请在 `chrome://extensions` 重新加载扩展并刷新 VGMS 页面。
